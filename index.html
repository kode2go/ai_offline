Setup in four steps

No installer is required. Keep the executable and model together using the folder layout below.

Create a folder

Create a folder anywhere on your computer, for example C:\OfflineAI.

Place the EXE inside it

Move OfflineAI.exe into your new OfflineAI folder.

Create the model folder

Inside OfflineAI, create a folder named exactly models.

Add the Qwen model and run

Put qwen2.5-0.5b-instruct-q4_k_m.gguf inside the models folder, then double-click OfflineAI.exe.

Final folder layout

OfflineAI\
├── OfflineAI.exe
└── models\
    └── qwen2.5-0.5b-instruct-q4_k_m.gguf
Once both files are downloaded, you can disconnect from the internet and run the chatbot locally. The GGUF file is the AI model; keep its filename unchanged.
