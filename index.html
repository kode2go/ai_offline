Setup in five simple steps

There is no installer and no manual model folder setup required. Offline AI handles first-run model setup for you.

Download OfflineAI.exe

Use the download button above to get the latest GitHub release.

Run the application

Double-click OfflineAI.exe. A startup splash appears while the application prepares to open.

Approve the model download

On first run, click Yes when Offline AI asks to download the Qwen2.5-0.5B model. This requires an internet connection and downloads about 491 MB.

Wait for first-time setup

The app creates the models folder, downloads the model, and then loads it. Startup itself may take up to around two minutes on some PCs; model download time depends on your internet connection.

Start chatting offline

Once the model has been downloaded, future chats run locally on your PC and do not require a cloud AI service or account.

Folder layout after first setup

OfflineAI\
├── OfflineAI.exe
└── models\
    └── qwen2.5-0.5b-instruct-q4_k_m.gguf
First run needs internet access. Offline AI only needs the connection to download the model. Once the model exists locally, normal chatbot inference runs on your computer.

Manual model setup

Automatic setup is recommended. If you prefer to install the model manually, create a models folder beside OfflineAI.exe and place the GGUF file inside it using the exact filename shown above.
